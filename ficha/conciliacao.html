Instalar o botão 📊 Conciliar grupo (WhatsApp Web, Safari ou Chrome)

1. Mostre a barra de favoritos (Safari: ⌘+Shift+B). 2. Arraste este botão para a barra:

📊 Conciliar grupo

3. No WhatsApp Web, abra o grupo Comprovantes de pagamento, clique no botão, escolha o período e clique em Ler e conciliar. Esta página abre com tudo atualizado.

Safari: se nada acontecer ao clicar, ative Desenvolvedor → "Permitir JavaScript do Campo de Busca Inteligente". O botão tem a chave da clínica: não compartilhe.
